# ReCoin

Windows 플레이용 빌드입니다.

## 다운로드 및 실행

1. **Code → Download ZIP**으로 저장소를 다운로드하고 압축을 해제합니다.
2. **Builds/Recoin-Windows.zip**도 전체 압축 해제합니다.
3. **Recoin.exe**를 실행합니다.

실행 파일과 _Data 폴더, MonoBleedingEdge, DLL 파일은 같은 위치에 유지해 주세요.

[빌드 ZIP만 바로 다운로드](https://github.com/kimsoo3884/ReCoin/releases/download/build-2026-09-29/Recoin-Windows.zip)
