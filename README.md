# ReCoin

점프·2단 점프·빠른 낙하로 장애물을 피하고 코인을 모으는 2D 액션 러너입니다.

## 최신 Windows 실행본

[ReCoin Windows ZIP 다운로드](https://github.com/kimsoo3884/ReCoin/releases/download/build-2026-10-18/ReCoin-Windows-WarningsFixed-20261018.zip) · [실행 안내·빌드 정보](https://github.com/kimsoo3884/ReCoin/releases/tag/build-2026-10-18)

2026년 10월 18일 생성한 Windows 64비트 포트폴리오 빌드입니다.

1. 위 실행본 ZIP을 다운로드하고 **전체 압축 해제**합니다.
2. **ReCoin.exe**를 실행합니다.
3. ReCoin_Data, MonoBleedingEdge, UnityPlayer.dll은 실행 파일과 같은 폴더에 유지합니다.

기본 조작: Space 점프·2단 점프 / S 빠른 낙하 / F 캐릭터 스킬 / Esc 일시정지. 설정에서 조작키·음량을 변경할 수 있습니다.
